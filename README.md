# Data-Warehouse

A branch `main` é protegida e não permite push direto.

Todas as alterações devem seguir o fluxo:

1. Criar uma branch a partir da `main`.
2. Implementar as alterações.
3. Realizar commits seguindo o padrão definido.
4. Enviar a branch para o GitHub.
5. Abrir um Pull Request.
6. Solicitar revisão de outro integrante.
7. Corrigir os apontamentos, caso existam.
8. Obter pelo menos uma aprovação.
9. Aguardar os testes automatizados.
10. Realizar o merge na `main`.

Não são permitidos:

- Push direto na `main`;
- Force push na `main`;
- Exclusão da `main`;
- Merge sem aprovação;
- Commits contendo dados sensíveis.
